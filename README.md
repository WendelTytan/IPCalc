# IP Calculator — IPv4 & IPv6

Uma calculadora de redes completa para IPv4 e IPv6, desenvolvida para facilitar estudos, configuração de redes e análise de endereçamento.

O projeto realiza cálculos automáticos de:

* IPv4
* IPv6
* Máscaras de rede
* CIDR
* Conversão binária
* Broadcast
* Hosts
* Network ID
* Sub-redes
* Compressão IPv6 (RFC 5952)
* Informações completas de rede

---

# Funcionalidades

## IPv4

* Cálculo de máscara CIDR
* Conversão decimal ↔ binário
* Network Address
* Broadcast Address
* Primeiro host
* Último host
* Quantidade de hosts
* Classe do IP
* Identificação de IP privado/público
* Máscara decimal e binária
* Subnetting

---

## IPv6

* Expansão completa do IPv6
* Compressão IPv6
* Compressão baseada na RFC 5952
* Identificação de prefixo
* Conversão hexadecimal
* Conversão binária
* Network Prefix
* Informações de sub-rede IPv6

# Objetivo do Projeto

O objetivo do projeto é fornecer uma ferramenta prática para:

# Recursos de Rede Implementados

## IPv4

| Informação | Descrição                       |
| ---------- | ------------------------------- |

| Broadcast  | Último endereço da rede         |

| Máscara    | Máscara decimal e CIDR          |
| Binário    | Conversão binária completa      |
| Sub-Redes  | Faça Sub-Redes                  |

---

## IPv6

| Informação  | Descrição                   |
| ----------- | --------------------------- |
| Compressão  | Compressão RFC 5952         |
| Prefixo     | Prefixo da rede             |

| Binário     | Conversão binária           |
| Expansão    | Endereço expandido completo |
| Sub-Redes   | Faça Sub-Redes              |
